# Movie Recommendation System

A final-year project that builds a movie recommendation engine using collaborative filtering and content-based approaches.

## Overview
This project recommends movies to users based on their viewing history and preferences. It leverages the MovieLens dataset to generate personalized suggestions.

## Features
- Collaborative filtering (user-based and item-based)
- Content-based filtering using movie genres and ratings
- Evaluation using RMSE and precision@k metrics

## How to Run
```bash
pip install pandas numpy scikit-learn
python main.py
```
